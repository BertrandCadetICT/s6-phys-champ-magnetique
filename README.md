# Champ magnétique terrestre — S6 Physique

Simulation pédagogique interactive en français : globe 3D, lignes de champ d’un dipôle idéalisé, composantes horizontale et verticale, inclinaison et axes géographique et géomagnétique.

Ouvrir `index.html` dans un navigateur, sans installation et sans dépendance externe. Compatible avec les API standard Canvas des navigateurs modernes, dont Safari sur Mac.

## Utilisation

- Glisser le globe pour tourner et utiliser la molette ou le curseur pour zoomer.
- Choisir une ligne avec la latitude de son pied ; déplacer le point le long de la ligne.
- Observer B, Bh, Bv et l’inclinaison dans le repère local.
- Comparer les axes, séparés initialement de 11,5° (valeur du cours).

Le pôle Nord magnétique terrestre a une polarité sud : les lignes de champ y entrent.

## Limites

Dipôle centré idéalisé, valeurs relatives, sans vent solaire ni anomalies locales. Ce n’est pas un outil de navigation. Le cours PDF et les documents personnels ne sont pas inclus.
